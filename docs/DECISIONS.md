# DECISIONS — принятые решения

| Дата | Решение | Почему |
|---|---|---|
| 18.10.2026 | Версия Godot — **4.7.2 stable** | Уже скачана у владельца, это актуальная стабильная версия |
| 18.10.2026 | Python 3.12 для `enginectl` | Уже установлен и прописан в PATH |
| 18.10.2026 | Код хранится в открытом репозитории krasking94/GodotAI | Решение владельца. Следствие: никаких секретов в репозитории |
| 19.10.2026 (план v2) | Сначала плагин к обычному Godot, форк — позже | Сборка Godot из исходников долгая; первый результат нужен быстро (см. PLAN.md, раздел 4) |
| 19.10.2026 | Игра запускается отдельным процессом Godot, а не кнопкой «Запустить» в редакторе | Так весь вывод игры попадает в файл лога, и ИИ читает его командой `log get` |
| 19.10.2026 | «Одной фразой» = фраза человека → ИИ пишет JSON-описание сцены → одна команда `scene build`. Языковая модель внутри enginectl не живёт | ИИ (Claude и другие) остаётся снаружи, как задумано в плане; enginectl и плагин — простые проверяемые инструменты без ключей и сети |
| 19.10.2026 | Персонаж — от первого лица, управление читается прямо с клавиш (W A S D, стрелки, пробел, мышь) без карты действий Godot | Карту действий пришлось бы править в project.godot отдельной командой; для первой версии проще и прозрачнее. Переход на карту действий (нужна для экранного управления на Android) — позже |
| 19.10.2026 | Машина — на встроенном VehicleBody3D, а не на своей физике | Из коробки едет, рулит и тормозит, описывается теми же операциями моста. Известные ограничения (нет предела скорости, может перевернуться) пока не мешают демо; свою физику писать только если упрёмся |
| 19.10.2026 | У игровых объектов есть режим самопроверки (`test_drive`/`test_program` у машины, отчёт «на полу» у персонажа), который печатает измерения в лог | ИИ не видит экран, но видит лог: так он проверяет физику и управление заездами без человека и ловит ошибки вроде переворота или падения с края до живой проверки |
| 19.10.2026 | Тест-программы объектов задаются командой `game run --test кто=программа`, а не записываются в сцену | Человек, запуская сцену, сразу получает управление; ИИ проверяет ту же сцену автозаездом без правки файла. Godot отдаёт всё после `--` скриптам через `OS.get_cmdline_user_args()` |
| 19.10.2026 | Разметка земли — шейдером по мировым координатам (`game/grid.gdshader`), а не текстурой | Без картинок и импорта, одинаковая клетка на плоскости любого размера; движение и повороты видны. Перёд машины обозначается формой (кабина ближе к переду, фары и стоп-сигналы), иначе глаз читает машину задом наперёд |
| 19.10.2026 | Выход из машины — по четырём точкам (двери, зад, перёд) с проверкой земли лучом и свободного места капсулой персонажа | Простая и предсказуемая проверка «нельзя выйти в стену» средствами физики Godot; если все четыре заняты, персонаж остаётся в машине и об этом печатается строка, которую видит ИИ |
| 19.10.2026 | Плагин перечитывает скрипт с диска при подключении по `res://` | Редактор без фокуса не замечает внешних правок файла; иначе ИИ, добавив `@export`, получает «нет свойства» при сборке сцены |
| 19.10.2026 | Папка `tools/` закрыта от редактора файлом `.gdignore` | Там Python и примеры, Godot их компилировать не должен (учебный сломанный скрипт давал красные ошибки при открытии проекта) |
