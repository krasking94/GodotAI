# Установка с нуля (для нового человека)

Эта страница для того, кто впервые видит проект и хочет запустить его у себя на Windows. Нужны три программы,
папка с проектом и одна команда для проверки. Ничего собирать из исходников не надо.

## 1. Три программы

1. **Godot 4.7.2** — https://godotengine.org/download/windows/ : обычная версия (не «.NET»). Это один файл
   `Godot_v4.7.2-stable_win64.exe`; положите его, например, в `C:\Godot\` и запускайте оттуда.
2. **Python 3.12** — https://www.python.org/downloads/ : при установке поставьте галочку **Add python.exe to PATH**.
3. **Git** — https://git-scm.com/download/win (можно всё по умолчанию). Без Git проект можно скачать и как ZIP
   (кнопка **Code → Download ZIP** на GitHub), но тогда обновления придётся скачивать заново.

## 2. Папка с проектом

В командной строке (клавиша Win, набрать `cmd`, Enter):

```text
cd /d C:\Godot
git clone https://github.com/krasking94/GodotAI.git
```

Появится папка `C:\Godot\GodotAI`. Обновить до последней версии потом можно так: `cd /d C:\Godot\GodotAI` и `git pull`
(при закрытом Godot).

## 3. Открыть в Godot

Запустить Godot → **Импорт** → выбрать `C:\Godot\GodotAI\project.godot` → **Импортировать и редактировать**.
Первый раз редактор минуту импортирует модели. В списке сцен слева внизу видно `scenes/yard.tscn` — это двор.
Кнопка ▶ (F5) запускает игру: W A S D ходьба, мышь обзор, пробел прыжок, E сесть в машину, Esc меню.

## 4. Проверить, что ИИ может управлять редактором

Не закрывая Godot, в командной строке:

```text
cd /d C:\Godot\GodotAI
py -3 tools\enginectl\enginectl.py doctor
```

Ответ `"status": "ok"` и «Godot на связи» означает, что мост работает. Если `python` вместо запуска открывает
Microsoft Store, всегда пишите `py -3`, как выше.

Дальше можно пробовать команды из [README](../README.md): комната одной командой
(`scene build --file tools\enginectl\examples\room.json`), запуск (`game run`), снимок (`game screenshot`),
сборка в один файл (`project export`, см. [EXPORT.md](EXPORT.md)).

## 5. Подключить ИИ

Мост не привязан к конкретному ИИ. Подходит любой помощник, который умеет запускать команды в папке проекта
(например, Claude Code или другой агент с доступом к терминалу). Дайте ему прочитать [AI_PROTOCOL.md](AI_PROTOCOL.md):
там все команды `enginectl` и формат описания сцены. Помощник объявляет задачу (`task begin`), работает командами,
закрывает её (`task end`); человек видит ход работы во вкладке **Задачи ИИ** рядом с Инспектором и может всё отменить
одной кнопкой.

Свой новый проект вместо демо: `py -3 tools\enginectl\enginectl.py setup --target D:\МойПроект --name "Проба"`,
затем открыть его в Godot так же, как в шаге 3.

## 6. Если что-то не так

- **«Godot не на связи»** — редактор закрыт, или проект открыт без плагина: **Проект → Настройки проекта → Плагины**,
  у AI Bridge должна стоять галочка. После `git pull` при открытом редакторе: **Проект → Перезагрузить текущий проект**.
- **«Файл подключения остался от закрытого редактора»** — просто откройте проект в Godot снова.
- **Игра не видна или чёрный экран** — обновите драйвер видеокарты; на слабых машинах в Godot поставьте
  **Проект → Настройки проекта → Rendering → Renderer → Compatibility**.
- **Windows предупреждает про неизвестный файл** при запуске собранного `GodotAI.exe` — «Подробнее → Выполнить
  в любом случае»: файл не подписан, это нормально для домашней сборки.

Готовая игра без редактора: `build\windows\GodotAI.exe` после `project export --preset Windows --release`
(шаблоны экспорта ставятся один раз, см. [EXPORT.md](EXPORT.md)). Этот файл можно отдать кому угодно, Godot
и Python ему не нужны.
